# ExpandThemeSystem

Intent: keep Coronatio themes as JSON while growing them into a mature UX token system.

Children:
1. `observeMatureThemeSystems` — extracts stable patterns from Material, Fluent, Primer, Carbon, Oracle Redwood, and enterprise appliance systems.
2. `declareJsonTokenGrammar` — names the token flags and flat JSON grammar Coronatio owns.
3. `proveUxLibraryExpansion` — binds the grammar to TestTab, CSS variables, tests, and live readback.
