# ObserveMatureThemeSystems

Material teaches role/on-role pairs, containers, outlines, state layers, and contrast pairing. Fluent teaches tokens across color, typography, spacing, elevation, and motion. Primer teaches foreground/background/border/shadow/pattern token families. Carbon teaches layered surfaces and theme-local component behavior. Oracle Redwood teaches product-wide theming with restrained brand stripes and enterprise clarity. Coronatio preserves the old HomeServer colors while adopting these durable token families.
