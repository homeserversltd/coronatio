# Contracts band

Recursive child band for Coronatio data contracts and readback types.

- `core.rs` — Core app state, pane, manifest, tab list, and visibility contracts.
- `registry-startup.rs` — Registry, startup, lane, fallback, admin, and Caduceus membrane contracts.
- `topics-stats.rs` — Topic catalog, monitor pulse, events, boundary, and stats contracts.
- `installer-registry.rs` — Installer, transaction, merge, starred-tab, config persistence, and rollback contracts.
- `service-storage.rs` — Service data, portal, broadcast, frontend storage, and persistence contracts.
